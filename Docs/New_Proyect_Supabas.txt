Nuevo proyecto para desarrollos
Estoy en proceso de planificación de un proyecto que me permita llevar el control de las actividades realizadas en cada visita de soporte y asesoría a mis clientes, para el cual he pensado en nombre como Sistema de Gestion de Visitas, Sistema de Control de Sesiones (SCS), Bitacora de Visitas, etc, en este punto el nombre esta pos definir aun.
Para éste nuevo proyecto en pensado lo siguiente:
    1. Debe ser una aplicación Web
    2. Utilizar Supabase como gestor de base de datos
    3. En la fase inicial y desarrollo utilizar GitHub Pages para desplegar todo el entorno web
    4. En ésta primera versión implementar un API para sincronizar una base de datos DBISAM con la de Supabase
    5. Utilizo VS Code generar el código  para el desarrollo.

Los preliminares del desarrollo estarán bajo el siguiente esquema de trabajo:
    1. Creación de Perfil en Supabese vinculado con GitHub
    2. Creación de entorno local para creación del código necesario desde VS Code
    3. Creación de base de datos en Supabase

Categorías de actividades que los consultores o personal IT deben realizar, ejemplo: Instalación de Sistemas Operativos, Inducción de Usuarios, etc

             j) ark_employees
Registro maestro para definir los empleados de los clientes a los cuales se les dará asistencia.
             k) ark_functional_units
Unidades funcionales del clientes, ejemplo; Departamentos, gerencias, etc.
             l) ark_it_assets
Registro maestro para llevar el inventario de los equipos y dispositivos del cliente a los cuales debemos hacerle servicios
